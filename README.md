# 📊 Influencer Giveaway Performance Dashboard
**Marketing Analytics Project**

### 🎯 Objective
To analyze the ROI of social media giveaway campaigns and identify which influencer categories drive the highest product sales. This dashboard provides a high-level view of awareness versus conversion.

### 💡 Key Insights
*   **Total Sales:** 75M units generated across all categories.
*   **Total Reach:** 15Bn estimated audience engagement (brand awareness).
*   **Top Performers:** The **Tech** and **Food** categories are the leading drivers of product sales.
*   **Platform Analysis:** The dashboard allows for instant filtering by Platform (TikTok, YouTube, Instagram) to see performance variations.
